# Virtual ECG Lab

Interactive ECG explorer. Web version of a Processing 4 sketch.

Live: https://simicm1987.github.io/VirtualECGLab

## Files
- `index.html` – page shell
- `style.css` – full-page layout
- `app.js` – converted Processing 4 application
- `data/mitdb/` – MIT-BIH record 100 (PhysioNet)
- `data/logo.png` – logo

## Controls
- Rhythm menu or **Up/Down** – normal, tachycardia, bradycardia
- **Space** – pause / play
- **R** – restart
- **C** – reference trace on / off
- Speed button – x0.5 to x2

Data: MIT-BIH Arrhythmia Database, PhysioNet.
